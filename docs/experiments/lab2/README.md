## Анализ и вывод

- `weather_2`, `weather_3`: модель выдумывала погоду и ссылалась на Open-Meteo без вызова инструмента. После правки `weather_2` исправился; `weather_3` остался ошибкой.
- `schedule_1`–`schedule_3`: модель требовала уточнения или описывала вызов кодом, хотя дату можно вычислить из доверенного времени. Повтор исправил завтра и воскресенье; сегодня осталось ошибкой.
- `reminder_1`–`reminder_3`: модель отвечала текстом вместо native tool call, просила повторно указать уже известную зону/год или обещала создать напоминание. Ошибки сохранились.
- Два обычных ответа и запрос уточнения были выбраны правильно в базовом прогоне.

Уточнение инструкции частично улучшило выбор инструментов, но не обеспечило надёжную маршрутизацию.
**В первоначальном прогоне критерии 10/12 действий и 8/9 аргументов не были выполнены.** Затем выбор native tool calls был исправлен и выполнен полный контроль: 11/12 действий и 8/9 аргументов (таблица выше). Результаты разных версий не объединяются.

## Артефакты и воспроизведение

- `routing-ipv4-2026-11-06.json` — полный исходный прогон: фактические вызовы/аргументы, ответы, длительности, каталог и настройки.

- `diagnostics/` — незавершённые сетевые попытки; они не входят в метрики.
- `live-smoke*.json`, `reminder-first-message-check.json` — прежние проверки работоспособности, не замена базового эксперимента.

Из корня репозитория (ключ берётся из `.env`, в отчёт не попадает):

```bash
dotnet build ItmoBot.sln --configuration Release
DOTNET_SYSTEM_NET_DISABLEIPV6=1 MCP_SERVER_PATH="$PWD/mcp/bin/Release/net10.0/ItmoBot.Mcp.dll" dotnet run --project tools --configuration Release --no-build -- evaluate-routing docs/experiments/lab2/routing-new.json
```

Для повтора ошибок добавьте путь исходного завершённого JSON после пути нового результата.
Текущая версия кода содержит изменённую инструкцию; новый запуск не воспроизводит старый промпт побайтно.
Исходная инструкция для базового прогона — AgentRequestBuilder без добавленного блока «Порядок выбора действия»; её SHA-256 сохранён в исходном JSON.
На этой машине .NET-запросы без IPv4 завершались `SocketException InvalidArgument`; переменная отключает IPv6 только для процесса эксперимента.
